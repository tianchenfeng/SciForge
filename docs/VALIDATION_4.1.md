# SciForge 4.1 验收记录

测试平台：Windows x64，Python 3.11，PySide6。测试输入、逐项日志、JUnit XML 和截图保存在本地 `test/acceptance_20261026`。公开仓库只保存测试代码和汇总，不上传实验数据。

## 测试方法

- 布局：800×560、960×640、1024×768、1280×720、1360×940、1920×1080；逐页检查控件边界、同级按钮交叠、导航选中状态和滚动可达性。
- 缩放：100%、125%、150%、200% 的 Qt 缩放因子。截图人工复核；无界面插件需要手动加载系统中文字体，该加载只用于自动检验。
- 统计：单/双因素，XLSX/CSV/TSV/TXT，零值、常量、负数、缺失、非数值、大小数值、不平衡分组、中文/特殊列名和长名称、多指标批量导出。
- 异常：空文件、损坏表格、不支持的文件、空分组、单水平、重复清理后列名、NaN、正负无穷和极端值。预期拒绝属于通过，必须返回明确原因，不能误报成功。
- 正确性：单因素 F 与 P 值对照 SciPy 独立实现；单/双因素在单位换算后 P 值保持一致。
- 配方：有效求解、不可行约束、空原料、重名、非法类型、负数和非有限数值；界面加减、上下限和禁用状态。
- 模块：产气、青贮、转录组原有验收脚本；代谢组单/双因素完整报告、嵌套验证及原有回归测试。
- 16S：合成的 Feature 表、taxonomy、metadata、环境指标、ASV 功能预测与 NSTI，运行单因素九阶段和双因素十阶段。
- 本地数据：抽取现有 Excel 的数值后重新分组，测试极大/极小缩放、离群值、缺失和行顺序变化。这些输出仅用于软件压力测试。
- 发行包：运行真实 EXE 的自检、16S 嵌入脚本、代谢组子进程，检查导出文件及进度/结果通信；解压验证和 SHA-256 校验。

## 数值边界

统计及代谢组导入层拒绝绝对值超出 `1e-150` 到 `1e150` 的非零输入，避免平方计算溢出或下溢。超出范围时提示换算单位；零值仍可输入。缺少可估计统计量的退化数据可能按原有规则输出 `NA`，测试不会替换算法或编造显著性。

这些测试覆盖了记录中的环境与数据形态，不能证明任意硬件、系统字体、所有数据文件都绝无问题。16S 测试不安装外部 QIIME2/PICRUSt2，不重新运行原始序列预测。

## 复现

安装项目依赖与 pytest 后，在仓库根目录运行：

```powershell
python -m pytest tests modules/module_stats modules/module_metabolomics/tests -q
$env:QT_SCALE_FACTOR='1.5'
python -m pytest tests/test_desktop_layout.py -q
python build_release.py
```

本地实验 Excel 不存在时，相应的本地数据变异测试会跳过；合成测试仍可独立复现。
